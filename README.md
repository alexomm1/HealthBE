# Project Health BE
Проект предназначен для прохождения психологического тестирования
## Запуск проекта
### Для запуска потребуется:
<li>Сгенерировать Django Key для проекта</li>
<li>Получить и установить в env ключи для Google OAuth</li>

## Библиотеки: 
<li>Django RestFramework</li>
<li>SimpleJWT</li>
<li>Django</li>
<li>pathlib</li>
<li>Datetime</li>
<li>dotenv</li>

После установки всех необходимых библиотек, требуется запустить миграции.
Далее запуск тестирования.
